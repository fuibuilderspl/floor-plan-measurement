Scale 比例校准▾

scale not set
Scan reads every printed dimension on the plan (needs internet the first time, ~15 s). Tap one → it zooms you to that number with the value filled in → draw the line over it → Apply. Or just draw manually: over a known dimension, or across a door leaf = 900 mm. Several references combine for a better scale.
Drew it wrong? Right-click (or the ⌫ / ↻ Redraw buttons) removes the last point or the whole line so you can draw it again. An applied reference can be removed with the ✕ next to it, or its ends dragged in Edit mode.

Spaces 空间与面积▾

Once the scale is set, this traces every enclosed room on the plan automatically and computes each area. It is a rough draft — check and fix corners in Edit mode.
Trace a room with Draw (click each corner; Enter or click the first point to close) or Rect (two opposite corners). Points snap to corners, walls, and align with other corners; a magnifier shows the exact spot (L to hide). Type a number + Enter = exact mm along the aim line. Shift = straight walls.
Made a mistake mid-draw? Use the bar at the top of the plan — ⌫ Undo point (or Backspace / right-click) and ✕ Start over (or Esc). Ctrl+Z undoes a finished room.
Edit mode: drag a corner, drag inside to move the room, arrow keys nudge, right-click a corner to delete, double-click a wall to add one.
On the card: click the name to rename · + / − add / deduct (voids) · ⧉ duplicate · blank rate = use the default.

Linear items 线性项目 · 按米▾

Work priced per running metre — wall hacking, skirting, cornice. Click along the run; Enter to finish. Each item has its own rate.

Count items 数量项目 · 按件▾

Work priced each — doors, windows, sanitary fittings, aircon points to remove. Click each one on the plan; Enter to finish. Quantity is editable.

Ruler 量尺 · 临时▾

Quick spot checks (ceiling height notes, a wall length) — not part of the quote. Click two points; each line is listed here. Right-click a line's end on the plan, or use ✕ below, to remove one.

Quote details 报价资料▾

Margin and GST are added on top of the subtotal in the quote total and the report.
